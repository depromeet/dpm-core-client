# Client 화면 Storybook

## Figma 시안 확인

시안을 반영하는 화면 작업이라면 구현 전에 대상 프레임으로 바로 열리는 Figma 링크를 받습니다. 링크나 확인 방식 중 이미 알려준 항목은 다시 묻지 않습니다. 둘 다 빠졌으면 한 번에 묻습니다.

> 대상 화면의 Figma 프레임 링크를 보내주세요. **Figma MCP**, **이미 로그인한 Chrome**, **앱 브라우저** 중 어느 방식으로 확인할까요?

- **Figma MCP**를 선택하면 현재 도구의 `figma-design-to-code` 스킬을 먼저 읽습니다. 제공받은 링크의 대상 프레임에서 `get_design_context`로 레이어, 컴포넌트, 스타일과 스크린샷을 확인합니다. 스크린샷이 응답에 없으면 같은 프레임에 `get_screenshot`을 사용합니다. 연결된 코드 컴포넌트나 토큰을 Client의 실제 사용처와 대조합니다.
- **Chrome** 또는 **이미 로그인한 브라우저**를 요청하면 [브라우저 확인 절차](references/figma-browser.md)에 따라 사용자가 로그인한 일반 브라우저 세션을 사용합니다. Chrome에서 열어 달라는 요청 자체를 방식 선택으로 봅니다.
- **앱 브라우저**를 선택하면 같은 절차에 따라 Codex의 `@Browser` 또는 Claude Code의 Browser 패널에서 프레임을 확인합니다.
- 프레임에 접근할 수 없거나 대상이 불명확하면 구체적인 원인을 알리고 공유 권한, 정확한 프레임 링크, 또는 해당 프레임의 이미지 중 필요한 것을 요청합니다. 다른 확인 방식으로 바꾸려면 사용자에게 먼저 확인합니다. 사용자가 시안 없이 설명만으로 진행하겠다고 하면 그 설명을 기준으로 삼습니다.

## 화면과 케이스 만들기

1. `apps/client/app`의 관련 화면과 공용 컴포넌트 사용처를 먼저 확인합니다. 제품에서 쓰는 화면 컴포넌트를 Storybook에서도 렌더링하고, 스토리에서 목 데이터와 필요한 이벤트 응답을 주입합니다. 새 화면 제안은 목 데이터로 확인 가능한 UI까지 구성합니다. 실제 서비스 경로·API·인증 연결이 필요한 부분은 PR 설명에 적습니다.
2. 화면과 가까운 `_storybook` 디렉터리에 케이스를 둡니다. 사이드바는 `Cases/화면/구역` 구조를 따릅니다. 따로 열어 검토할 가치가 있는 상태는 스토리로 만듭니다. 같은 모습과 동작이 나오는 조건은 대표 스토리의 `parameters.caseConditions`에 적어 **화면 조건**으로 보여줍니다.
3. 클릭·입력·제출의 결과는 해당 초기 화면의 하위 테스트로 붙입니다. 홈은 Storybook 10.6.8의 CSF Next `.test()`를 사용합니다. 이름은 “틀린 코드를 제출하면 다시 입력할 수 있어요”처럼 행동과 기대 결과를 적습니다. 케이스를 전환하거나 다시 실행하면 쿼리 상태, 폼 입력, 알림이 초기화되는지 확인합니다. 기존 사례를 하위 테스트로 옮길 때는 주소를 유지하고, 사이드바에서 중복되는 기존 항목은 `!dev`로 숨깁니다.

## 검증과 예제

- `pnpm storybook:client`로 [로컬 Storybook](http://localhost:3000)을 엽니다. 대표 화면을 직접 조작하고 하위 테스트에서 같은 동작이 재현되는지 확인합니다. Figma를 참조했다면 선택한 방식으로 확인한 프레임과 Storybook 화면을 대조합니다.
- `pnpm --filter client check-types`와 `pnpm build-storybook:client`를 실행합니다. 리뷰하는 사람이 쉽게 열 수 있도록 스토리 이름이나 링크, 보고 싶은 상태, 동작 재현 방법을 남깁니다.
- 홈 예제는 [활동 흐름과 출석 테스트](../../../apps/client/app/%28home%29/_storybook/home-lifecycle.stories.tsx), [프로필 저장과 첫 이용 가이드](../../../apps/client/app/%28home%29/_storybook/home-guidance.stories.tsx), [홈 목 데이터](../../../apps/client/app/%28home%29/_storybook/home-cases.ts)를 참고합니다.
