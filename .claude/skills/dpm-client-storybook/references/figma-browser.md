# 브라우저로 Figma 시안 확인

1. 사용자가 지정한 브라우저에서 Figma 프레임 링크를 엽니다.
   - **일반 Chrome**을 요청하면 Figma에 로그인된 기존 Chrome 프로필을 사용합니다. Codex 데스크톱에서는 연결된 Chrome을 선택하고, Claude Code에서는 [Claude in Chrome](https://code.claude.com/docs/en/chrome)이 연결돼 있으면 사용합니다. 대상 프레임이 이미 열려 있으면 그 탭에서 확인하고, 새 탭이 필요하면 같은 프로필에서 엽니다.
   - **앱 브라우저**를 선택하면 Codex 데스크톱의 [`@Browser`](https://learn.chatgpt.com/docs/browser) 또는 Claude Code 데스크톱의 [Browser 패널](https://code.claude.com/docs/en/desktop)을 사용합니다.
2. 프레임 이름과 열린 시안이 요청과 일치하는지 확인합니다. 캔버스 배율과 위치를 조정해 전체 프레임을 캡처하고, 필요한 경우 읽기 어려운 부분을 확대해 추가로 캡처합니다. 메뉴와 레이어 패널을 조작할 때는 현재 브라우저 도구를 사용하고, 캔버스 안의 시안은 실제 화면에서 봅니다.
3. 화면 구성, 문구, 간격, 아이콘을 캡처와 기존 코드에서 대조합니다. 정확한 치수·토큰이나 에셋이 구현을 좌우할 때는 프레임 상세 정보나 추가 캡처를 요청합니다. Client를 구현한 뒤 로컬 Storybook에서 같은 화면 크기와 상태를 비교합니다.
4. 요청받은 Chrome에 연결할 수 없거나 프레임을 열 수 없으면 막힌 지점을 알립니다. 해당 브라우저가 로그인을 요구하면 사용자에게 직접 로그인할 수 있도록 넘깁니다. 프레임 캡처를 받거나, 사용자가 선택하면 다른 방식으로 확인합니다.
