# 앱 브라우저로 Figma 시안 확인

1. 현재 세션에서 브라우저를 조작할 수 있는지 확인하고, 사용자가 준 Figma 프레임 링크를 엽니다.
   - **Codex 데스크톱**에서는 [앱 브라우저(`@Browser`)](https://learn.chatgpt.com/docs/browser)를 사용합니다.
   - **Claude Code 데스크톱**에서는 [Browser 패널](https://code.claude.com/docs/en/desktop)을 사용합니다. 일반 Chrome에 이미 로그인해 있고 [Claude in Chrome](https://code.claude.com/docs/en/chrome)이 연결된 환경이라면, 사용자가 그 Chrome에서 확인해 달라고 한 경우에 사용합니다.
2. 프레임 이름과 열린 시안이 요청과 일치하는지 확인합니다. 캔버스 배율과 위치를 조정해 전체 프레임을 캡처하고, 필요한 경우 읽기 어려운 부분을 확대해 추가로 캡처합니다. 메뉴와 레이어 패널을 조작할 때는 현재 브라우저 도구를 사용하고, 캔버스 안의 시안은 실제 화면에서 봅니다.
3. 화면 구성, 문구, 간격, 아이콘을 캡처와 기존 코드에서 대조합니다. 정확한 치수·토큰이나 에셋이 구현을 좌우할 때는 프레임 상세 정보나 추가 캡처를 요청합니다. Client를 구현한 뒤 로컬 Storybook에서 같은 화면 크기와 상태를 비교합니다.
4. 로그인 화면이 나오면 사용자에게 해당 브라우저에서 직접 로그인하도록 안내합니다. 도구가 없거나 로그인 뒤에도 프레임을 볼 수 없다면 프레임 캡처를 요청합니다. Figma MCP로 방식을 바꿀 때는 사용자에게 선택을 확인합니다.
